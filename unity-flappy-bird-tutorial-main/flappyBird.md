For this Unity project, I decided to modify the original Flappy Bird demo and turn it into my own game. I’m a bird lover, and my favorite type of bird is the shrike. I know that modern cities aren't exactly the best living environments for birds. They can crash into tall buildings and windows, and sometimes they eat food scraps from the trash, which can be really harmful to them. So I came up with the idea of making a game where a little bird flies through a city while trying to avoid different obstacles.
 I also wanted to change the original cartoony art style into something more realistic. I decided to set the game in a dark city at night, and I drew all the art assets myself. My first challenge was adjusting the background. The original game used low-poly, pixelated graphics, while my background was much larger and more detailed. It was quite difficult to get everything to fit properly, and I had to resize and compress the background several times before it finally worked. 
Another big challenge was adding more obstacle prefabs. At first, I thought I could simply duplicate the original pipe prefab, change its appearance, and reuse the same scripts. However, I soon realized that it wasn't that simple. The original pipe prefab consists of an upper and a lower part, and the script was written specifically for that structure. My new obstacles didn't have two parts, so the script wouldn't work if one of them was missing. I even tried to cheat the system by adding an empty GameObject as a placeholder, but that didn't work either. In the end, I had to write separate scripts for each new obstacle prefab. It's a bit complicated and probably not the most efficient way to code it, but hey, at least it works! 
My next challenge was figuring out how to make different obstacles spawn randomly. The original game only had one type of obstacle, so I needed to change the spawning system. My first attempt was to create an array that stored all the prefabs using the original Pipes script. This worked at first, but it became a problem once I started using different scripts for different obstacles. Eventually, I found another solution: instead of making the array detect specific scripts, I made it store GameObjects directly. That worked perfectly, and now the game can randomly spawn different obstacles. 
There are still a few small bugs I want to fix, though. For example, my stop sign obstacle isn't long enough, so sometimes it looks like it's floating in the air instead of standing on the ground. In the future, I'd also like to experiment with the gameplay mechanics a little more instead of just changing the visuals. One funny idea I had was to let the bird poop on obstacles to earn bonus points or something like that. I think that would make the game a little more entertaining and give players something else to do besides just avoiding obstacles.
